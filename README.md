# CS331_Lab3_Cryptography

## Author: Lex Watts

### How To Run

**Prereqs:**<br>
Make sure your system has a Python compiler!

Firstly, clone this repository using the command:<br>
git clone "https://github.com/LexW2007/CS331_Lab3_Cryptography"<br>

Then, navigate to the directory Part2/src/ using the command:<br>
cd CS331_Lab3_Cryptography/Part2/src

Lastly, once in the src directory, run the command:<br>
python ceasercipher.py

### Using The Program

Once you run the program, you will be prompted to either encrypt or decrypt a message. Enter E/e for encryption and D/d for decryption.

After you chose, enter the message you'd like to encrypt/decrypt.

Then, enter the key (shift) value. If encrypting this will shift forward, if decrypting this will shift backwards.

The program will then output the result for users to see.
